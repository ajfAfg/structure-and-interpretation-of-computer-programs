# 新しい型や新しい演算を追加するために必要な変更

|                                              |           新しい型の追加           |         新しい演算の追加         |
| :------------------------------------------: | :--------------------------------: | :------------------------------: |
| 明示的ディスパッチによるジェネリックスタイル | 既存の全ての演算を変更する必要あり |             特になし             |
|              データ主導スタイル              |              特になし              |             特になし             |
|         メッセージパッシングスタイル         |              特になし              | 既存の全ての型を変更する必要あり |

## 新しい型あるいは新しい演算がよく追加されるシステムでは、どの組み立て方が最適？

新しい型がよく追加されるシステムでは、メッセージパッシングスタイルが最適。逆に新しい演算がよく追加されるシステムでは、明示的ディスパッチによるジェネリックスタイルが最適。

データ主導スタイルはどちらの場合でも最適。（あえてデメリットを挙げるなら、もし静的型付け言語なら網羅性判定ができない点かな。）
